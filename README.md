# Title
Deep Learning Classificaton of Pneumonia from Chest X-ray Images 

## Team members
Kylah Gunter (kylahgunter), Alesha Raihana (azraihana)

## Project description
In this project we develop a deep learning model to classify chest X-ray images as either normal or pneumonia. Chest X-ray imaging is commonly used in hospitals to diagnose respiratory diseases, including pneumonia. The dataset used in this project is from Kaggle. It is a Chest X-ray Pneumonia dataset containing labeled images of normal lungs and pneumonia cases.  

The goal of our project is to train neural network models to automatically classify chest X-ray images. We plan to compare two approaches: a simple convolutional neural network and a transfer learning model such as MobileNetV2 and evaluate performance by using accuracy and loss on the test dataset.
